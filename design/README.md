# 🎨 Дизайн-воркспейс SoiLüDi

Это папка и ветка **`design`** — рабочее пространство дизайнера. Оно **отделено от `main`**, чтобы
эксперименты с вёрсткой и макетами не попадали на живой сайт.

> **Главное правило:** работаем в ветке `design` (или в своих ветках от неё). **В `main` не пушим.**
> `main` = продакшн, он авто-деплоится на https://creox-ch.github.io/slswiss/. Туда изменения попадают
> только через ревью и мёрж, а не напрямую.

---

## 📁 Куда что класть

```
design/
├── README.md      ← этот файл
├── mockups/       ← макеты, экспорты из Figma (PNG/JPG/SVG/PDF)
├── assets/        ← иконки, логотипы, шрифты, картинки
└── prototypes/    ← черновая HTML/CSS-вёрстка, если пробуешь в коде
```

Всё, что относится к дизайну, складывай сюда, в `design/`. Не трогай `index.html` и `tests/` в корне —
это боевой код и тесты.

---

## 🚀 Как начать работу

```bash
# 1. Склонировать репозиторий (один раз)
git clone https://github.com/creox-ch/slswiss.git
cd slswiss

# 2. Переключиться на ветку дизайна
git checkout design

# 3. Работать в папке design/ ...

# 4. Сохранить и отправить свои изменения
git add design/
git commit -m "design: <что сделал>"
git push origin design
```

> Хочешь отдельную под-ветку под конкретную задачу? `git checkout -b design/<название>` от `design`,
> потом Pull Request в `design` (или в `main`, когда готово к прод-ревью).

## 👀 Как посмотреть вёрстку

**Живой preview пока не настроен** (планируется отдельно — Netlify branch-deploy или GitHub Pages через
Actions). Пока варианты:

- Открыть свой HTML-файл **локально** в браузере (двойной клик по файлу).
- Смотреть боевой сайт для референса: https://creox-ch.github.io/slswiss/ (это `main`, не твоя ветка).

Когда настроим preview-URL для ветки `design` — допишем сюда ссылку.

## 🎨 Бренд-референс (из `index.html`)

- **Основной голубой:** `#00AEEF` / `#1AABEF`
- **Красный (швейцарский крест):** `#D52B1E`
- **Тёмный фон hero:** градиент `#0A1628 → #0a2540 → #0d3060`
- **Шрифты:** `Inter` (текст) + `Plus Jakarta Sans` (заголовки)
- Приложение — это **один файл** `index.html` (single-file SPA). Стили лежат в `<style>` внутри него.

---

## ⚙️ Про тесты и деплой (чтобы не пугаться)

- CI (GitHub Actions, Playwright) запускается **только на `main`** — на ветке `design` он НЕ гоняется.
  Так что можно спокойно пушить в `design`, ничего «красного» это не поднимет.
- На прод (`main`) любые правки идут через ревью. Дизайн-эксперименты в `design` прод не задевают.
