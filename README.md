## Перед возобновлением

Уточнить продуктовую цель, нужную базу и окружение; прочитать package.json и
CI текущей ветки; запускать тесты только с разрешёнными тестовыми учётками.
Документирование не запускает старые e2e на живой платформе и не применяет SQL.
